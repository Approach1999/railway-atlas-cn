# 相机变化后名称候选等待正确视野

2026-10-28，构建index-D4TfdCvK.js，名称缓冲仍512，原数据/分类/颜色未改。

新增回归模拟相机已改变但轨道源仍报旧视野loaded的时刻：原实现立即查询旧瓦片，断言2次查询!=应有1次，确实失败。
cameraChanged现在只标记候选失效与cameraPending，随后的筛选也不能在此期间准备缓存；到地图idle且轨道源loaded、相机停止后，才释放门禁并查询新视野。
reset清除门禁；缩放旧名称仍隐藏到新来源完成。原缩放生命周期测试改为先确认idle之前保持隐藏，再确认idle后完成可见；初次遗漏此新等待条件的失败日志保留。
