## 更正上轮的方向判断

上轮点字幕配置 text-max-width=0，本意是不折行，但在锁定 MapLibre 6.15 的 point 模式中，
该值实际以零宽度进入排版，使中文逐字折为竖列，再按切向旋转。
因此，当时截图的交错/方向不稳不能直接归因于短源片段方向。这是原型设置错误，现予更正；
极短泛化几何的方向可靠性仍需独立核对，不能从这次更正反推其已通过。
原有产品沿线标签不使用这个点字幕参数，本问题发生在隔离原型内。

新增 line-label-presentation.ts：短片段使用正值 64 em 的排版宽度、水平单行名称、
12 px 长的细引线锚定原片段中点。引线是本机生成的图标，与文字共同参与避让；
不添加轨道几何、不把引线当成铁路、不增加字体或第三方图片请求。
长片段仍沿自己的路径放字，短注记不借其他同名 way 延长路径。

## 实际绘制与拒绝守卫

将 point 字幕宽度故意恢复为 0，实际浏览器产生 20 个可观察的纵向文本碰撞框。
新守卫读取实际放置字幕的原生碰撞框，对含至少三个中文字的字幕要求宽大于高，
确认这份失败样例被拒绝；不会仅因构建通过或源参数存在就宣称排版正确。
守卫是这批中文单行注记的回归检查，不是所有字体、拉丁短词或字形像素的全面证明。

正确宽度下，文字 padding=12 与 20 的四画面对照使用逐字节相同的候选数据：

| 画面 | padding=12 实际锚点 / 短注记 | padding=20 实际锚点 / 短注记 | 名称文字种类 |
| --- | ---: | ---: | ---: |
| 概览 z10 | 53 / 27 | 46 / 20 | 两者均 16 |
| 概览 z10.5 | 56 / 28 | 51 / 23 | 两者均 16 |
| 西部站场 | 15 / 1 | 14 / 0 | 两者均 4 |
| 电车交汇 | 6 / 0 | 6 / 0 | 两者均 3 |

padding=20 使注记更疏，同时保持这四个画面的文字种类；这不是对全部区域/名称覆盖的保证。
概览中的沈山北道线仍被碰撞遮住，但保留 31 个候选，单名称隔离时可实际绘出。
四画面均无 <300 CSS px 同身份重复；候选重放仍字节相同，锚点偏差最大 0.493 px。
43 个已绘中文字字幕通过新的实际形状检查。截图已目视核对单行和短引线。

等待条件也补充核对：不能仅等 Map.loaded/瓦片就绪，还需新名称桶进入当前 placement，
并完成淡入。初次采集曾在新桶放置前读出零锚点，该观测不作为产品空白或通过证据。
另一次采集代码的局部变量遮蔽错误已修正，未影响产品。
