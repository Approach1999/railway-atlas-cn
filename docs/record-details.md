# 地图与文字列表的详情字段

2026-10-24。`record-fields.ts` 统一字段规则，`RecordFields.tsx` 同时渲染地图和文字列表的属性及来源。
基于真实抽查包检查发现，原地图没有直接显示轨距/桥隧/运营方，原列表与地图对完整性/别名等解释不同。
本轮补齐并统一，不把原始 JSON 折叠区存在某标签等同于已经提供了所需的可读字段。

- 轨道显示等级、名称/分类依据和规则号、显式运营方、service/usage、高速/限速/电气化、轨距及桥隧。
  标注值原样保留；`no`、多值轨距和特殊桥隧类型不改写为猜测；限速不能推断高铁或运营状态。
- 车站点、乘降所、电车站点与站区分别标识；展示别名、编码和有明确记录的关联对象，不显示轨道专用属性。
- 设施展示类别、制式、明确关联/未确认，以及有原标签时的编号/运营方/容量/用途；不按邻近车站推断归属。
- 保留全部线路身份及配色证据；`line_complete=false` 不再写成“单一线路关联”，而明确关联不完整。
  源关系成员齐备也明确不代表实际运营线路完整；缺关联写“尚未建立完整线路关联”。
- 来源区区分源对象时间、源快照时间和数据构建时间，展示分类/配色版本、提供方、覆盖矩形与非行政边界说明。
  当前快照的 manifest 随地图详情选择一起固定；文字列表用自己实际加载的 manifest，不从当前日期猜数据时间。
- 详情底部增加数据/许可/免责声明入口；关于弹窗的开关由 React 处理，WebGL 构造失败后仍可打开和关闭。
  关于/分享共用首尾焦点循环，关于有明确名称和最小 44px 关闭目标；关闭上层说明返回原记录按钮。

文字列表按需独立读取当前快照线路目录，和地图使用同样的显示名称。该目录失败时保留 source ID、已加载对象及详情，
提供独立重试；15 秒超时或旧请求按代次/取消清理，恢复不重载对象索引、不改变 URL/选择，且不抢新操作焦点。
旧 schema 未提供线路目录时不强行请求，也不伪装成完整线路身份。

```powershell
npm run build --prefix apps/web/client
npm test --prefix apps/web/client
python scripts/serve_probe.py --port 8766
# 另一个终端设置 PLAYWRIGHT_MODULE 与 PREVIEW_URL
node scripts/verify_detail_fields.cjs

```

48 项单元/领域测试通过；新增检查覆盖原标签直读、缺失不推断、站区/设施与轨道适用范围、共享/不完整关系、时间区分。
12 个真实样本覆盖桥、隧、五类铁路等级、共线/缺色/浅色、站区、地铁站点和转车盘，地图/列表字段与完整来源逐项一致。
浏览器同时验证源 JSON、版本/范围、线路名称 503 独立恢复、焦点、嵌套说明，以及 WebGL 失败入口。
列表 5 组、详情竞态/窄屏 4 组、分享 7 组回归通过；截图已查看，保留面板可滚动和顶部关闭入口。

这不是全 106 样本人工验收，不证明分类正确或实际运营，更不是两名独立签字/读屏/真实设备验收。
配色核对日期与关于页上下文现见 [后续实现](about-data.md)；其他原 MVP 缺口仍须继续；原列表偶发超时未据此归因为已修复。
