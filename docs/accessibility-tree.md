# 浏览器辅助树：地图区域与键盘说明

2026-10-28，构建 `index-DHoae-HU.js`，数据和地图样式保持不变。

## 实际发现

修改前 Chromium 辅助树中有两个名称均为“沈阳铁路地图”的嵌套 region：容器section与MapLibre画布。
画布DOM虽然有aria-describedby，引用的文字位于默认折叠的键盘帮助details中，实际辅助树没有提供description。
这两项在真实浏览器辅助树中失败，其余搜索/筛选/对话框状态检查通过，原记录保留。

地图容器现在用普通div，保留地图画布自身的命名region与键盘焦点。
完整操作说明改为面板之外的sr-only文字，始终可作为画布的描述；展开帮助后仍显示同一文案，使用同一常量避免两份文字漂移。
紧凑面板收起时，搜索控件从树中排除，地图完整描述仍存在；恢复按钮、搜索和对话框没有改交互。

使用CDP Accessibility.getFullAXTree/getPartialAXTree读取浏览器实际计算结果，保存原始树；不是只检查HTML里写了ARIA属性。
核对地图命名region唯一且有完整描述、折叠面板后的描述与开关名称/expanded、具名combobox及展开状态、实际activedescendant关系对应已选option、结果名称和制式、底图switch状态、要素详情region与标题、分享模态名称/URL字段焦点与背景排除、列表模态/搜索名称、建设状态checkbox、空视野polite状态与恢复按钮。
