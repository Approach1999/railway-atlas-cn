# 实施与验收计划 · v1.2

本计划把全国目标拆成可验收批次；不是把全国范围改为仅沈阳。
当前需求与架构基线已完成，后续各门槛是正式产品实施事项。
v1.2 决策：扩展设施集、线路等级与地铁线路配色、分享快照保留 12 个月、
验收覆盖桌面四浏览器 + Android + iOS + 平板。

## 全国阶段资源实验

先下载并保留已校验的日期 PBF（本次没有成功下载）。
记录 CPU/内存/磁盘、版本、输入字节、墙钟、峰值 RAM、临时磁盘峰值与输出大小。
在 16 GiB RAM、至少 40 GiB 空闲磁盘的 Linux 构建环境做首次基准；这是预算起点，非测量结果。
单次构建若超过 12 GiB RAM 或 30 GiB 临时磁盘，应先分块/磁盘索引改造再扩规模。
不得将城市探针直接吞全国 PBF；不得通过省略引用或随机丢轨道掩盖资源问题。

全国验收需覆盖普通线、高铁标注、城轨、工业线、站场、生命周期、设施类别与跨省边界，
每类至少 10 个样本；报告明确哪些区域无数据、哪些字段缺失。
选取跨省边界的完整 way 检查去重与连续性，不将 relation 不完整误报为几何完整。
全国初始构建若不能在预算内完成，记录瓶颈并采用并行分块/磁盘索引；
API 不能解决离线数据构建失败，也不能用城市结果冒充全国完成。

## 风险与处置

| 风险 | 处置 | 阻断的交付 |
| --- | --- | --- |
| 数据源连通/下载变化 | 日期快照、哈希、保留原件；连接恢复后单独验证 | 日期 PBF 的生产试验，不阻断当前有界样本结论 |
| station 同名/多几何 | 保留源身份，关联证据与审核 | 错误合并时阻断发布 |
| 分类缺失/冲突 | unknown/conflict、源标签与覆盖说明 | 不把未知强行归为运营/国铁/高铁 |
| 设施类别多/分类冲突 | facility_kind 映射、规则版本、每类人工样本 | R13 与设施批次发布 |
| 官方线路色未公布/色值变化 | `confidence=operator-map/manual`、来源与核对日期、人工覆盖 | R16 线路批次发布 |
| 共线/线路关系不完整 | `line_shared`、回退色、详情列出全部线路与完整性 | 共线错误归属时阻断发布 |
| 线路色对比不足/色觉不可辨 | 深色 casing、自动徽标文字、非文本对比与色觉抽测 | N09 与 R16 |
| 可访问性/浏览器矩阵扩大 | 键盘/屏幕阅读器回归、真实 iOS/Android/平板设备 | P2 验收 |
| 第三方底图/字体隐私 | 域名清单、隐私说明、CSP/Referrer-Policy、必要时自托管 | R15/N07 与公开发布 |
| 12 个月保留的存储成本 | 按快照体积×12 估算并设预算；超预算再评估保留期 | N06 或成本门槛 |
| 全国内存/磁盘 | 先分区、测峰值、必要时磁盘索引 | 全国数据交付 |
| 大瓦片/手机卡顿 | 分级过滤、懒加载索引/详情，按实测再评估 WASM | 未达 N01–N04 不发布对应规模 |
| CDN 不支持 Range 或缓存错位 | 206/Content-Range/CORS/缓存实测；换兼容服务或独立 MVT 路径 | PMTiles 线上发布 |
| 无底图/错位/授权不清 | 选定授权底图并做坐标锚点检查；不静默变换原数据 | 正式公开地图 |
| 公开地图适用事项未确认 | 按发布主体、地域与实际服务核实审核/备案等条件 | P5，不能当作技术可行即已获上线条件 |

中国境内公开地图相关事项参考
