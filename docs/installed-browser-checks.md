# 本机 Chrome 与 Edge 核心流程核对

后续已补入[官方 Firefox 两主版本](firefox-core.md)，并修复列表标题可见性；以下保留 B5DC1WQs 构建的原始 86 项范围。

2026-10-27。产品保持 `index-B5DC1WQs.js`，本轮没有修改应用行为。
把六个既有功能驱动的浏览器目标参数化，串行对本机安装的 Chrome 和 Edge 执行相同流程。
通过浏览器协议核对实际执行文件，并记录产品、精确版本、User-Agent、Windows 版本及启动条件。
不是通过修改 User-Agent 冒充另一个浏览器。

| 实际执行目标 | 精确版本 | 产品协议返回 | 结果 |
| --- | --- | --- | --- |
| Google Chrome | 155.0.8059.85 | Chrome/155.0.8059.85 | 六组、43 项通过 |
| Microsoft Edge | 156.0.4314.42 | Edg/156.0.4314.42 | 六组、43 项通过 |

两者都使用各自新的隔离环境、无头模式，并显式设置 SwiftShader 参数，关闭底图、不产生第三方请求。
额外 enable-automation 参数用于读取实际启动文件；本轮不验证这些浏览器的全部默认图形配置或性能。
最初读取启动文件时，协议拒绝未带 enable-automation 的请求，补齐该测试参数后，两目标身份核验与全部流程通过。
这属于测试驱动条件，不是产品兼容性故障。

## 六组覆盖

| 流程 | 每浏览器项数 | 代表性证据 |
| --- | --- | --- |
| 搜索 | 9 | 真实索引、20 条上限、上下键、活动后代、合成输入法事件、快速提交与详情、窄屏选择目标 |
| 筛选 | 8 | 保持键盘焦点与原控件、预设/撤销、空筛选、版本与分享状态 |
| 列表与键盘 | 5 | 按需索引、真实车站/设施详情、焦点交还、地图聚焦、模拟 WebGL 失败、索引/详情故障恢复 |
| 分享 | 7 | 当前可见/原筛选、选中身份、重新打开、迟到复制结果隔离、空筛选、窄屏模态焦点 |
| 资源恢复 | 10 | 真实数据上的 503/损坏响应、保留已有轨道/详情、显式分项重试、焦点和版本状态 |
| 地图字体 | 4 | 实际 FontFace 注册、原生完整性校验、503/损坏/头等待、重试清空回退字形且保留画布/URL |

每份通过报告都绑定其实际浏览器与驱动指纹；矩阵记录应用入口及 JS 指纹，结束后入口未改变。
归档时再次核对当前 JS 内容与矩阵起始值相同。所有成功报告的 pageerror 和外部请求数组为空。
最终共 12 组、86 项通过，没有据此关闭其他未覆盖的需求。

## 范围边界

这里只证明这两个安装版本和这些流程；尚未满足“桌面四浏览器各最近两个稳定版”。
常用安装位置未找到 Firefox；Safari、iOS/Android/平板未在本机验证。
窄屏是视口模拟，输入法、WebGL 丢失和剪贴板用例含合成/拦截手段，不能替代 OS 输入法、真实故障、实际剪贴板权限或用户操作验收。
旧 Edge 200% 走查仍保持原执行记录，不能据此次无头测试补填其未知版本。
NVDA/VoiceOver、完整对比度、独立数据审查等门槛继续开放，MVP 仍在推进。

## 复现

设置 PLAYWRIGHT_MODULE 指向可用 Playwright 安装，启动既有预览；驱动只访问本机页面。
每次使用新的 PREVIEW_EVIDENCE 目录保留历史结果。

```powershell
$env:PREVIEW_URL='http://127.0.0.1:8766'
$env:PREVIEW_EVIDENCE='data/manifests/local/installed-browsers/new-run'
node scripts/verify_installed_browsers.cjs
```

可用 ATLAS_BROWSER_CHANNELS=chrome 或 msedge 选择目标，ATLAS_TEST_SUITES 选择已登记的组；
单组脚本使用 ATLAS_BROWSER_CHANNEL。缺失浏览器、进程失败、报告/身份不匹配都不能算通过。
矩阵不安装浏览器，不复用用户正在使用的浏览器资料，不修改应用数据。

[矩阵与指纹](evidence/installed-browsers.json)、[逐组结果](evidence/installed-browsers-matrix.json)。
首次实际执行的编排器以及之前字体驱动按原 SHA 留存于 evidence/history，后续编排器另外补入自身指纹和 JS 结束校验，
没有把这两项后补检查改称首次运行时已执行。
