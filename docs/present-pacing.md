# 呈现节奏调查：空白 WebGL 慢帧与当前环境复测

2026-10-31。产品代码未改：本次构建 `index-D4TfdCvK.js` SHA-256 `227835ec35388d01e5bd2297426e2f34ef92b7c3b5ef0ff1934f93416a94a2cc`，与 2026-10-30 交接基线逐字节一致；快照、数据、配置均未变。本轮只做诊断与复测。

## 背景与问题

2026-10-28 记录：正式地图 30 秒闭合拖动默认/软件 render 间隔 p95 为 35.0/37.0 ms（目标 ≤33 ms）；
分组隐藏文字、描边、设施、轨道乃至全部内容均不改善（35.8–37.0 ms）；主线程 CPU 95.5% idle；
同日空白页面两次 rAF p95 仅 10.2 ms，但**每帧 clear 的空白 WebGL2 画布页面 rAF p95 为 34.6 ms**，
与地图同为 Intel Arc/ANGLE(D3D11) 路径。[原件索引](evidence/pan-layer-decision.json)当时未确定根因。

## 历史原始数据的时间结构分析（本轮新增）

对 2026-10-28 空白 WebGL 控制原始帧序列（2002 帧，sha256 `cdba44ea…`，原件在交接 checkout
`data/manifests/local/pan-layers/scheduler-webgl/report.json`）逐帧复核：

- >25 ms 共 348 帧（17.4%），慢帧值几乎全部量化在 **33.9–35.1 ms**（≈2 个 16.7 ms vsync 周期），
  中位慢帧 34.2 ms；正常帧中位 10.1 ms。
- 慢帧不按固定周期出现，而是**成簇爆发**（相邻慢帧间距 1/2/3 帧的占多数），随后回到连续 10 ms。

该形态是**间歇性跌落到约 30 Hz 的调度/呈现行为**，与"每帧渲染成本过高"不符——后者会表现为
与内容量相关的连续高间隔，而不是 60↔30 Hz 之间的量化跳变。这与分层隐藏实验（内容多少不影响 p95）
互相印证：历史 p95 抬升不是应用绘制内容造成的。

## 受控实验：当前环境未复现

新增 `scripts/diagnose_present_pacing.cjs`（诊断页，无地图引擎/应用代码；协议逐行复刻
`diagnose_pan_scheduler.cjs`：同 HTML 结构、1040×1000 画布、WebGL2 属性、30 秒闭合拖动、
rAF/longtask 采样）。串行运行，全部 protocol valid、0 页面错误、0 长任务：

| 运行 | 条件 | rAF p95 | 备注 |
| --- | --- | ---: | --- |
| R1 | 无头 Chrome 156.0.8078.74，D3D11，1040×1000，每帧 clear | **8.4 ms** | 2026-10-28 同协议为 34.6 ms，未复现 |
| R2 | 有头 Chrome 同上 | 8.4 ms | 有头/无头无差异 |
| R3 | 无头，`--use-angle=gl`（OpenGL 4.5） | 16.7 ms | 全程稳定 30 Hz（median 16.7，max 933 ms），比 D3D11 慢但不同形态 |
| R4 | 无头，画布 260×250 | 8.4 ms | 尺寸无关 |

当前环境所有空白控制都干净；今日中位帧间隔 8.3 ms（≈120 Hz 节拍）也不同于历史 10.1 ms，

156.0.8078.48 → 156.0.8078.74；驱动/系统状态变化不能排除，本机无法回装旧补丁做 A/B）。

## 结论与边界

1. **历史 ~35 ms p95 及"空白页面同样慢"是环境绑定现象，不是应用代码问题**：产品 JS 字节未变，
   空白对照与正式地图同步转干净；历史分层隐藏（全隐藏仍 35.8 ms）与本轮时间结构分析共同支持该归因。
   交接清单中"先调查浏览器图形呈现/合成、驱动与测量条件"一项，本轮以受控对照给出了答案：
   现象随浏览器补丁版本（或其他环境状态）消失，无需也无法通过删减应用功能解决。
2. 当前本机默认路径测量低于 N03 的 33 ms 口径；**N03 不据此通过**——正式验收对象是真实
   中端 Android/iPhone/平板与桌面浏览器，仍待真实设备。
3. 单轮限制：每配置一次运行，非随机重复推断；空白控制与无头/有头都是诊断条件，不代表物理
   显示交付或真实设备；未放宽阈值、未剔除样本、未改产品代码与数据。
4. 桌面电池复测（筛选/冷启动/热搜索）结果见 [本轮性能汇总](present-pacing-20261031.json) 所引原始报告；
   真实设备、在线底图与全部筛选组合等既有门槛保持开放。
