# 沈阳铁路图集：启动与试用

这是一轮10–15分钟的功能与易用性试用。数据、真机性能、独立审核和公开发布仍按原需求分别验收；完成本页任务不代表全部MVP通过。

## 需要哪些设备

先用现有Windows电脑和任意一台方便使用的手机开始，缺少设备的项目留待后续，无需专门购买。

| 用途 | 完整验收需要 | 使用方式 |
| --- | --- | --- |
| 桌面 | 现有Windows电脑 | Chrome/Edge/Firefox；NVDA读屏另测 |
| Android | 一台真实中端Android手机 | Chrome；日常普通设备即可，记录型号、内存、系统和浏览器版本 |
| iPhone | 一台真实iPhone | Safari；另用VoiceOver完成读屏任务 |
| 平板 | 一台iPad或Android平板 | 默认浏览器；横竖屏、触控、详情遮挡和软键盘 |
| macOS Safari | 借用或已有的Mac | 桌面Safari验证；不能用Windows浏览器模拟代替 |

正式浏览器版本范围见[需求§5.1](requirements.md)。第一轮不要求立刻凑齐设备。远程模拟视口与自动化测试可以辅助排错，不能填写为真机结果。
正式性能采样另配置10Mbps/100ms、冷缓存30次、热查询100次、站场30秒固定轨迹等条件；手动秒表或“感觉流畅”不能替代这些记录。

## 在当前电脑上启动

1. 打开仓库目录，双击根目录的 `start-preview.cmd`。
2. 启动器检查数据和依赖、构建页面、启动服务，确认首页及对应数据可读取后打开浏览器。
3. 保持命令窗口开启；按 `Ctrl+C` 停止。浏览器地址默认为 `http://127.0.0.1:8766/`。

也可以在PowerShell的仓库根目录运行：

```powershell
.\start-preview.cmd
```

常用选项：

```powershell
# 只检查准备条件，不构建或启动
.\start-preview.cmd --check-only
# 已有构建且本轮没有改代码时，可跳过构建
.\start-preview.cmd --no-build
# 端口被其他程序使用时，保留它并换一个端口
.\start-preview.cmd --port 8767
```

macOS/Linux或不使用cmd时，可运行 `python3 scripts/start_preview.py`；启动器只用Python标准库。

## 手机通过同一Wi-Fi试用

1. 电脑和手机连接同一可信Wi-Fi。若已有8766服务，先在它自己的窗口停止，或选择另一端口。
2. 电脑在仓库根目录运行：

```powershell
.\start-preview.cmd --lan
```

3. 用手机浏览器打开启动器列出的电脑Wi-Fi地址，例如 `http://192.168.x.x:8766/`（请使用实际打印的数字，不要照抄示例）。多网卡时选电脑Wi-Fi的IPv4地址，必要时用 `ipconfig` 查看。
4. 手机上的 `127.0.0.1` 指向手机本身，不能连接电脑。手机分享链接也应使用这个局域网入口；电脑若要分享给手机，请同样通过局域网地址打开地图后再分享。
5. Windows若询问防火墙访问，可仅允许当前可信专用网络；启动器不会修改防火墙、路由器或端口转发。访客Wi-Fi/设备隔离可能阻止互访。
6. 无法自动复制链接时，使用页面提供的手动复制方式。局域网HTTP可能限制剪贴板等浏览器能力，不能当作正式HTTPS验收。

如果铁路可见但手机的外部底图无法加载，而电脑能访问OpenStreetMap，可关闭原服务后运行：

```powershell
.\start-preview.cmd --lan --basemap-proxy
```

这会让手机通过电脑请求底图，图源仍为OpenStreetMap；仅转发当前交互视野，保留署名、应用标识、来源Referer与缓存/条件请求，不预取、不打包离线瓦片。电脑需能联网。
缓存存于被Git忽略的 `data/manifests/local/basemap-cache/`；此选项只用于本地试用，不代表已确定公开发布的底图方案。政策依据见[OSM瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)。

默认启动不监听局域网；`--lan`会监听本机所有IPv4接口，仅在上述试用网络中启用。试用结束关闭服务，不需公开部署或上传原始数据。

## 如果拿到的是新克隆

启动器不会下载大数据、安装依赖或覆盖快照。至少需要：

- Python 3.10或更新版本（项目使用3.12）与Node.js/npm；可使用已有 `.venv`。
- 前端依赖：`npm ci --prefix apps/web/client --ignore-scripts`。
- 默认快照 `data/processed/shenyang-mvp-geometry-20261027`，包括manifest、索引、详情分片及瓦片。这些生成数据被Git忽略，单独克隆仓库不会获得。

已有电脑上的已校验快照可以复制到同名目录，再运行 `python scripts/verify_snapshot.py data/processed/shenyang-mvp-geometry-20261027`；保留原快照，不覆盖旧分享数据。
从源文件重建时，先读[固定日期数据与工具链](real-shenyang-data.md)及[几何修订](mvt-integrity.md)。旧日期示例不能直接充当新快照；新建输出并核验后再用启动器的 `--data-dir` 指定。
准备条件检查只是排除缺文件等启动问题，不代表来源、分类或几何审核通过。

## 10–15分钟试用任务

复制一份[空白记录表](qa/trial-session-template.md)，每位参与者、每台设备分别记录，保留未执行项为空或“未测”。
正式形成性试用至少3名未参与开发的人，含铁路兴趣用户和普通地图用户，每人分别在桌面和手机执行一次核心任务；开发者演示不能代替。

先让参与者自行尝试，再提供帮助；记录求助和原话。以下任务对应[原U01–U08及通过条件](usability-review.md)，不减少原验收范围：

| 编号 | 给参与者的任务 |
| --- | --- |
| U01 | 指出一条高速线和一条普速线，读出能看到的线路名和主要站名；未标注时说明它未标注。 |
| U02 | 找到铁路沈阳北站，并说明它和同名地铁站的区别。 |
| U03 | 仅看高速，再恢复之前的图层，最后回到沈阳试验区。 |
| U04 | 保持仅地铁筛选，搜索查看铁路沈阳站，关闭详情后继续看地铁。 |
| U05 | 在密集站场选一条侧线，再选旁边的车站。 |
| U06 | 手机上打开详情、返回列表，再拖动地图；同时观察软键盘与关闭按钮。 |
| U07 | 找出数据截至时间，移动到覆盖外，再回到试验区。 |
| U08 | 临时仅看某线或显示被筛选隐藏的结果，分享链接，在新标签页打开并核对所见。 |
| S01 | 关闭底图，继续查站和选线路，再恢复底图；记录哪种更容易辨认。 |
| S02 | 打开文字列表，尝试不用点击地图也能查站和查看来源详情。 |

S01/S02是本轮补充观察，不替代U01–U08或完整N09。地图中“当前标注”不等于已核实运营，不要求参与者猜测缺失数据。

遇到打不开地图、对象身份选错、筛选无法恢复、详情/键盘遮挡操作等问题，记录复现步骤、设备、版本和截图后集中修复。
优先修阻断任务的问题，再复测失败任务；不要在一次小样本试用后宣称全面易用性通过。
