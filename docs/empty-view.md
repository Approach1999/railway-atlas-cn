## 实际问题与修复

以真实快照选择轻轨制式（当前源数据没有此制式记录），地图没有渲染任何对象，但旧构建 `index-tJmMJPE_.js` 的地图提示为空且隐藏。
这不同于明确取消全部类型，也不同于视野超出发布范围。现有检查在修改前复现并保存了零渲染对象、空提示与构建指纹。

现在地图空闲且轨道、车站源和瓦片全部就绪、无资源加载/错误时，核对当前实际绘制的轨道、车站、站区、设施和选中对象。
没有可见对象时提示“当前视野在这些筛选下没有可见要素”，并建议调整筛选或平移；低缩放同时提示支线和站场线的放大门槛。
提示描述当前视野，不声称整份数据没有该对象、不把缺失标注解释成现实没有铁路。

仅在 idle 检查，不在每一帧或鼠标移动时查询。相机开始移动、筛选改变和资源状态变化时清除旧空视野结论，待完整绘制后重判。
已有选中对象被隐藏/临时显示、显式空筛选、单线缺失及超出覆盖范围提示优先。
资源失败与加载保持各自恢复入口，不把未能读取的内容当作空数据。
沿用已有 React role=status 提示节点，保持同值不重复通知；不加入额外弹窗或强制移动焦点。
