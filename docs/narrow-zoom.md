# 更窄窗口的实际200%缩放

2026-10-28，当前构建 index-DQDm9VWe.js。

旧紧凑布局仅在CSS宽500/560px以上启用。在1024×768、1024×720和800×720物理窗口的真实200%缩放下，CSS视口约499×334、499×310、387×310，仍复现提示挡工具栏、缩放控件压住文字以及缩小按钮与署名重叠。

现在所有宽不超过700px、高不超过500px的紧凑窗口共用布局：缩放控件横排靠上、工具栏略上移，提示用更紧凑的内边距与并排动作，为地图署名和比例尺留出底部空间。
第一轮仍有比例尺与提示框重叠，检查拒绝；随后调节底部间隔和比例尺边距通过。没有改字体大小、原有面板高度或数据。

独立配置的浏览器默认缩放设置为100%与200%，viewport=null；CDP确认zoom=2、pinch/scale=1、CSS zoom=1，DPR翻倍、CSS宽约减半且字体声明不变。
五种物理窗口1552×1000、1280×800、1024×768、1024×720、800×720；Chrome156.0.8078.48和Edge156.0.4314.42共312项，其中10项为100%对照。
