# 补齐其他轨道等级的控制入口

2026-10-28，构建 `index-CtFMFhkg.js`，默认几何快照不变。

## 漏项与修复

数据模型和URL允许line_class=other，现有配色也提供“其他轨道”，但地图详细筛选、文字列表和图例只列出六种非城轨等级，遗漏other。
修改前用真实数据和有效的types=rail&classes=other分享状态复现：地图开关、列表开关和图例均不存在。
当前快照other等级轨道数为零；这项缺口是合法筛选状态无法在界面中编辑，不是当前源分类丢失，也不虚构有此等级的实际线路。

新增共享FILTER_RAIL_CLASSES，从现有等级集合排除三种城轨等级，得到七种非城轨等级。
地图、列表和等级图例都使用同一集合，保留未知等级；城轨仍按制式/线路筛选，不改变等级绕过规则。
自定义限制等级时，地图摘要也提示车站不推断线路等级；列表说明明确车站/设施不据此归类，避免合法筛选后仍见车站而误解成筛选失效。
原有八个模型函数源码（仅归一化换行）和所有旧导出值不变；没有修改分类、轨道可见性算法、源数据或快照。

配色校验允许九种必需等级、other可缺。新图例因此兼容没有other条目的合法配色，用与地图未匹配等级相同的#8a8f98回退，避免读取缺失entry导致界面崩溃。
当前实际配置仍使用原other配色#6b7c86，不重写源配色。
