# 架构草案

范围：全国铁路，沈阳验证第一条纵向链路。此处为规划，非已实现能力。

1. 数据来源：Geofabrik 中国 OSM PBF。用 Osmium 按区域裁剪、保留铁路标签及引用节点。
2. 数据处理：后续 Rust crate 负责标签归一、几何与拓扑分析；保留 OSM 类型、ID、原始标签和快照信息。
3. 首个展示：TypeScript + MapLibre GL JS，先用小型派生数据验证线路、站点和要素查询。
4. 全国规模：评估矢量瓦片 / PMTiles。需要动态查询时，再增加 Rust API 与空间数据库。
5. 性能：先测数据量、解析和交互耗时，再决定是否把计算迁入 Rust/WASM。

第一阶段验收：可从记录的同一快照重跑提取；线路几何引用完整；
能识别沈阳站、沈阳北站周边铁路并人工检查结果；地图有 OSM 署名。
OSM 标签与几何不直接等价于运营线路、实时运行状态或完整时刻表。

区域裁剪保留完整 way，可能延伸出矩形；跨区线路关系可能不完整。
首期不承诺全国路由或跨区关系闭包，扩展前应重新设计关系与拓扑处理。
