# 站名消歧与已确认关系的重复名称收敛

2026-10-26。R17 的站名检查发现：原标签对地铁追加制式文字，但无名对象也会生成“ · 地铁”；
铁路、有轨电车、轻轨等缺少同等提示。多个站点有明确关系时，仍各自提交同一站名，选中标签也不带制式。

## 行为

- 有名称的站点/站区统一追加铁路、地铁、轻轨、有轨电车、其他轨道或制式未标注；设施保持自己的源名称。
- 无名对象不生成名称标签，继续保留符号、来源身份、搜索/列表与详情；不在地图编造名称。
- 只有双方 link_status=confirmed、station_links 互相引用、有效 relation 证据集合完全一致、
  制式及去首尾空白后的源名称相同，才进入同一名称组。不靠名称、距离或邻近线路推断关系。
- 组内优先显示配置重点站，其次按 typed ID 稳定排序；过滤掉当前标签锚点时由仍可见的成员承接。
  没有确认、单向链接、不同关系集合、不同名称或不同制式保持独立。
- 全部点符号和原始记录保持独立，不合并来源对象。选中成员已绘出名称时不再提交同组普通名称；
  关闭选中后恢复一份普通站名。隐藏且没有临时显示的选中对象不会抑制仍可见的站名。
- 标签分组按不可变车站文档缓存；源更新缓存同时比较有序身份与标签文字，
  避免可见身份不变但标签变化时错误跳过更新。

没有更改源数据、关系判定、地图筛选、搜索排序、选中 typed ID 或详情中的原始名称。
确认关系的真实性仍需独立审核；本轮只使用数据已声明的证据，不自行给审核项签字。
