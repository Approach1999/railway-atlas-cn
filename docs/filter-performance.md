# 筛选后地图更新的测量与车站源去重

后续名称管线曾出现性能回退；2026-10-27 已[复用当前视图的名称几何](line-label-filter-cache.md)，最新桌面结果见该页。
本页保留此前车站源去重的原构建证据。

2026-10-25。此前的“界面更新与两次 rAF”只说明界面反馈，不能证明轨道已经反映新筛选。
本轮增加两个本地标记：轨道、车站源完成加载后的首次 render，以及之后的 idle。
每次都检查实际图层无缺失、没有资源错误，并核对绘制轨道等级：仅高速必须只含 high_speed，概览必须恢复其他等级。
这些仍是浏览器渲染提交，不能当成物理 GPU 或显示器呈现。

## 去掉重复提交

切换预设会清空选择，再刷新图层。此前即使没有选中对象，也会向选中源提交空集合；
清空选择和刷新图层还会各向车站源提交一次数据。
“铁路概览”和“仅高速”的车站可见集合相同，却触发了车站工作线程重新处理。

车站源现在比较源对象、不可变车站文档引用及有序可见 typed ID；三者相同就跳过 setData。
切换文档（即使 typed ID 相同）、重建源、筛选改变可见集合、选中或取消选中车站仍会提交。
只有已经为空的同一个选中源才跳过重复清空，实际选中几何继续照常更新。
没有改动车站标签、线路配色、数据、筛选规则或图层数量。

## 同条件测量

Chrome 155.0.8059.85、Windows 10.0.26200 x64、Intel Core Ultra 5 125H、1440×1000，
10 Mbps / 100 ms 模拟网络，底图关闭、第三方请求为 0。
默认路径实际为 Intel Arc / D3D11；软件路径显式为 SwiftShader。
每组从“仅高速”开始，串行交替切换概览/仅高速 100 次；另测真实沈阳北站场 z15.5、设施开启。
锚点 node/676578837 的源名称为“沈阳北”；此前文字误写为“苏家屯”，已更正，原始输入与测量数字未改。

| 场景 / 路径 | 应用规则 p95 | 首次源就绪 render p95 | 后续 idle p95 |
| --- | ---: | ---: | ---: |
| 概览 z10.5 / 默认，去重前 | 15.8 ms | 142.3 ms | 723.4 ms |
| 概览 z10.5 / 默认，去重后 | 7.7 ms | 71.0 ms | 665.8 ms |
| 站场 z15.5 / 默认，去重前 | 7.7 ms | 40.4 ms | 639.7 ms |
| 站场 z15.5 / 默认，去重后 | 8.5 ms | 38.9 ms | 639.2 ms |
| 概览 z10.5 / 软件，去重后 | 27.9 ms | 201.4 ms | 780.7 ms |
| 站场 z15.5 / 软件，去重后 | 29.1 ms | 171.4 ms | 653.2 ms |

“应用规则”包含同步图层更新和地址写入，不等同 React 已绘制完控件。
idle 还包含符号与过渡完成等等待，不能与按钮反馈时间混用。
概览默认路径的观测 p95 从 142.3 降至 71.0 ms；站场前后差异很小，不宣称有可归因的改善。
软件路径没有本轮去重前对照，不宣称软件提速；当前两场景的源就绪 render p95 都超过 100 ms。

去重后的 400 次切换中，车站源与空选中源的重复提交计数均为 0。
默认两场景及软件概览没有 >50 ms 长任务，软件站场有 2 次，原始时长保留在报告中。
完整 N02 仍有真实设备、其他筛选组合和实际呈现等缺口；也没有用本轮筛选结果覆盖之前软件平移超目标的 N03 记录。

## 正确性与限制

67 项单元/领域检查及严格 TS/checkJs、生产构建通过。
新增实际车站检查覆盖两次选中/取消后恢复、切城市轨道后无法再拾取该铁路车站、回概览后恢复选择；
两次真实制式切换各提交车站源一次。
版本切换 8 项、资源故障恢复 10 项及筛选控件 8 项回归通过。

首次并行运行筛选控件与目录回归时，筛选脚本曾等待“已切换数据版本”超时。
当时脚本关闭了浏览器，未取得失败时页面状态，原因尚未证实；单独复跑及同一并行组合再跑均通过，也不能说明该超时已修复。
脚本现会在失败时保存状态和截图，保留此稳定性缺口。

诊断默认关闭，仅 canvas 的 `atlas:profile-filters`、detail `{active:true}` 显式开启，`false` 停止；
非 boolean 忽略，每次最多记录 1,000 次应用及相应 render/idle，重新开启清空旧标记。
新动作替换未完成的旧动作，到上限也清除待记录动作，避免把新视图误标为旧修订。
标记保留在当前页面，不发送网络请求，不暴露地图实例或视图坐标。
