# 表单边界与键盘焦点的对比度

2026-10-27。当前构建 index-Cc2uO5a7.js / index-DfhfmoQw.css。
根据 [W3C 非文本对比说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)，
用于辨认控件与状态的视觉信息按未四舍五入的 3:1 阈值核对；有清楚文字/图标的按钮不因此要求每条装饰边框都加深。
本次针对用于辨认输入区域的作者定义边界，未将结果扩大为完整 WCAG 2.2 AA 验收。

## 发现与修改

搜索框、地区/版本选择、分享链接、列表查询/类别及列表分享链接，沿用的浅色边界 #a8bfba
对白色为 1.9397:1，对搜索框暖白底为 1.8803:1。
统一改用表单边界色 #6b8580，相应为 3.9683:1 和 3.8468:1。
这次修改四条表单样式规则和一项颜色变量；说明卡片/分组的装饰线以及铁路数据、线色、字体和交互规则保持原范围。

第一次修改脚本误判同色出现次数，保护断言阻止写入；随后验证明确拒绝旧样式（42 个状态失败）。
确认另有说明卡片使用同色后，只对四条表单规则精确修改，再重新构建与测量。
修复前观测、未生效时的失败和最终结果分别保留，未把一次空修改或观察模式的退出码当作通过。

## 实际浏览器结果

七个活动控件：搜索框、地区选择、数据版本、地图分享链接、列表查询、列表类别、列表分享链接。
每个控件检查默认、悬停、实际 Tab/Shift+Tab 后的键盘焦点；浏览器为实际安装的 Chrome 155.0.8059.85 和 Edge 156.0.4314.42。
各测试 1440×1000 与 390×844 两种视口，每浏览器 42 个状态，共 84 个。

| 检查 | 最低计算值 | 阈值 |
| --- | --- | --- |
| 四边边界与内外相邻背景 | 3.8468:1 | 3:1 |
| 活动字段普通文字 | 11.4980:1 | 4.5:1 |
| 存在的占位字 | 5.8566:1 | 4.5:1 |
| 实际可见键盘焦点轮廓 | 4.5926:1 | 3:1 |

所有边界为不透明、可见、至少 1px 的实线；焦点必须实际匹配 :focus-visible，轮廓至少 2px。
本次脚本读取当前浏览器 computed style，并验证加载的 CSS 路径、入口/JS/CSS 内容指纹。
背景按祖先颜色逐层合成；遇到未建模的背景图、透明整体或不支持的颜色表示会拒绝，而不是默默计作通过。
两浏览器最终失败数、pageerror 和文档外部请求数组均为空。

## 检查边界

这是上述七类作者样式控件的计算色对，不是全部控件或全部页面状态。
不包括原生下拉弹出菜单、文字选区、抗锯齿边缘/实际视觉、读屏、真实移动设备或完整 WCAG。
浏览器使用独立无头环境和已记录的软件渲染启动参数；390px 是模拟视口。
列表生成分享链接时拦截剪贴板写入，未修改用户系统剪贴板，也不将该步骤作为真实剪贴板权限验收。
没有重新运行历史性能/Firefox/全部功能矩阵，其报告继续保持原资产与范围。

## 复现

设置 PLAYWRIGHT_MODULE、PREVIEW_URL 和新的 PREVIEW_EVIDENCE，选择 ATLAS_BROWSER_CHANNEL=chrome 或 msedge：

```powershell
node scripts/verify_field_contrast.cjs
```

`--observe` 只用于保留对照观测，报告仍明确写 fails-threshold；正式验证无此参数，低于阈值会以失败退出。
脚本按顺序检查两种视口，性能测试期间不要并发运行。
