# 易用性走查与任务验收 · v1.3

日期：2026-10-22。依据当前探针和 v1.2 规格进行桌面走查，结论是设计判断，
尚未组织真实用户测试，也未验证正式手机界面。以下决策已纳入 v1.3 设计与 R17/R18，
不是已实现功能清单。

## 优先处理的问题

| 优先级 | 用户遇到的问题 | 设计决策 | 验证 |
| --- | --- | --- | --- |
| P0 | 看到彩色轨道却不知道是哪条线、哪个站 | 区域级显示主要线路名与站名，普通站随放大出现；深色字配浅色描边，线路名沿轨道；同名铁路/地铁注明制式 | U01/U02 |
| P0 | 首屏五组筛选太多，改完不知道为什么空了 | 常用预设在前，“更多筛选”折叠；显示可移除的筛选摘要；空结果区分视野外、筛选隐藏、缺少数据；独立“恢复默认图层”和“回到试验区” | U03 |
| P0 | 搜索到车站却要清空全部筛选才能看 | “显示此结果”只临时显示单个对象，关闭详情恢复；保留查询和列表滚动位置 | U04 |
| P0 | 站场线太细，手机点不中或总选错 | 放大命中容差，候选列表显示名称/类别/制式，不加粗所有线；标签也可点击；触屏不依赖悬停 | U05 |
| P0 | 详情打开后车站藏在抽屉下面 | 按可用地图区域调整 padding，仅必要时平移；关闭按钮常驻，返回保留搜索位置 | U06 |
| P1 | 高铁红与地铁红相近，浅色线路看不清 | 线路号、不同 casing、图例和线型配合；选中不换原色；真实底图与色觉模拟检查 | U01/U05 |
| P1 | 不知道当前看的范围和新旧 | 常驻区域名、源数据日期、比例尺；覆盖外提示可回到试验区；技术规则/原始标签放折叠来源区 | U07 |
| P1 | 分享后的图与自己刚才所见不同 | 临时隔离/结果显示的分享策略明确，链接打开后提示选中显示例外，不偷偷重置筛选 | U08 |

P0 表示沈阳正式产品的首批交互实现顺序；P1 也须在 P2 出口完成，不表示可跳过验收。

## 首屏与操作文案

- 搜索框：“搜索车站，例如沈阳北站”；下方说明“沈阳试验区”，避免让人误以为可以搜索全国线路。
- 主入口：“铁路概览 / 仅高速 / 仅普速 / 仅地铁”；“更多筛选”显示当前生效项数。
- 当前状态使用“当前标注”，短说明“地图记录，不保证运营”；不使用“仅当前运营”。
- 细节开关使用“站场与设施”，说明“放大后显示”；低缩放开启时提示可放大，不显示成开关失效。
- 默认开启车站名称；在更多显示选项提供“线路名 / 站名”开关。关闭站名仍保留站点符号、搜索与点击能力。
- 缺失值“未标注”、视野外“当前数据未覆盖此处”、筛选为空“当前筛选下没有可见记录”分别处理。
- 不在主界面展示 schema、typed ID、GeoJSON/PMTiles 切换、构建耗时；这些保留在来源或开发探针中。

## 任务验证

首次可交互的 P2 版本邀请至少 3 位未参与开发的人（至少 1 位铁路兴趣用户、1 位普通地图用户），
桌面和手机各执行一次核心任务；记录设备、快照、版本、用时、误选次数、是否求助与原话。
下表时间从可用地图/任务说明就绪起算，不替代 N01 的加载性能测试。
这是形成性测试；少量样本只能发现问题，不能宣称统计意义上的易用性水平。

| 编号 | 给用户的任务 | 通过条件/初始目标 |
| --- | --- | --- |
| U01 | 在区域视图指出一条高速线、一条普速线，并读出可用线路名和主要站名 | 不打开技术来源即可辨别；30 秒内；无来源名称缺失时能正确说明缺失，不诱导猜测 |
| U02 | 找到铁路沈阳北站，说明它与同名地铁站的区别 | 30 秒内选择正确对象；标签无覆盖；返回结果保留查询与滚动位置 |
| U03 | 仅看高速，再恢复原来的图层；最后回到沈阳试验区 | 30 秒内；预设不会被旧筛选抵消；撤销准确恢复，恢复图层不移动地图 |
| U04 | 保持仅地铁筛选，搜索并查看铁路沈阳站，然后继续看地铁 | 30 秒内；不用清空筛选；关闭详情后恢复原图层，查询仍保留 |
| U05 | 在密集站场选择一条侧线，再选择旁边车站 | 手机 45 秒内，最多两次误选；所有重叠候选可访问，不依赖悬停 |
| U06 | 手机打开详情、返回列表，再继续拖动地图 | 选中对象、关闭按钮与必要署名可见；软键盘不挡住全部结果；无滚动陷阱 |
| U07 | 判断数据截至何时，移动到覆盖外，再回到试验区 | 30 秒内；不把空白误读为没有铁路；无需读 OSM 原始标签 |
| U08 | 在临时仅看某线/显示隐藏结果时分享，并在新窗口打开 | 接收页恢复所见或所选原筛选，区别有说明；关闭临时详情恢复链接筛选 |

记录每位参与者结果，不把开发者操作演示记作独立用户测试。任务失败后先修阻断项，
再针对失败任务复测；键盘、屏幕阅读器、标签/配色/字体异常另按 N09 与设计 §10 检查。

## 此轮暂不扩展的内容

线路名称搜索、拼音搜索、最近记录、收藏、路线规划和新手导览暂不增加到 v1。
先使地图自带标注、常用入口和错误提示足够清楚；真实任务反复出现相同需求时再立项。
