# 当前构建的Firefox与恢复入口

2026-10-28，产品构建保持 `index-COabTbcb.js`，默认快照 `shenyang-mvp-geometry-20261027`，本轮没有修改产品代码或数据。

## 范围与结果

使用已有官方Firefox158.0.1和157.0.1，不据此断言它们现在是最新两个发行版。
重新核对固定官方安装包/驱动压缩包SHA和大小；运行文件与此前已验证报告相同，没有执行安装器或更改用户配置。
独立测试配置存放被忽略的本地目录，W3C WebDriver返回实际版本、Build ID、无头模式与配置路径；没有伪造UA或关闭Firefox内容隔离。

每版本通过六项核心任务：完整41层地图/名称与自托管字体、键盘平移缩放、沈阳北真实铁路站点搜索、分享及新导航恢复同一typed ID、高速/概览切换、列表键盘详情与标题可见。
另各七项恢复检查：真实空视野键盘恢复及相机/查询/版本/底图偏好保持、撤销、空线路及失效线路只解除线路限制、超出覆盖回到试验区、矮窗口九点遮挡与横向溢出检查、紧凑恢复返回地图焦点。
共12项核心与14项恢复任务。

紧凑原生窗口设为650×500，实际CSS视口两版本均650×427。提示、动作、工具栏、缩放控件、署名的九点取样均可命中目标。
这是真实Firefox小窗口，不是Firefox200%页面缩放，不能替代此前Chrome/Edge的实际缩放检查或完整N09。
保存了两版本地图、列表详情、紧凑恢复截图；实现者复核了158版本紧凑截图，不作独立人工验收。

## 失败与等待条件

第一次在受限进程环境启动后，页面尚未加载即出现Browsing context has been discarded，日志记录SpawnTarget子进程创建失败；与既有受限环境问题一致。
同一二进制以正常进程权限运行后通过核心任务，没有降低Firefox自身安全隔离设置。
首轮新增恢复任务又在导航时读到空文档，旧等待条件只要求任意恢复按钮曾存在，不能证明目标文档已经挂载。
现在导航前给旧文档设置唯一测试标记，要求新文档不含旧标记、readyState=complete且出现本任务指定动作，避免沿用旧页条件。该标记只存在测试页面，不修改产品。
严格等待后两个版本全部列明任务通过。原失败JSON、截图、进程及浏览器日志和前一版脚本保留。

[完整证据、源文件、构建和运行文件指纹](evidence/firefox-current.json)。浏览器日志含自身图形/任务栏/实验设置诊断，不宣称整个浏览器日志无错误。
最终页面Resource Timing没有外部文档资源；这不等于拦截了整个会话请求，也不能证明浏览器后台完全没有网络活动。
