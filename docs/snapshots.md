# 本机数据目录与快照

当前为沈阳单区开发预览。目录用于选择已有数据版本，不代表 MVP 已通过或已公开发布。
旧源快照仍没有城市轨道关系与对象版本元数据，切换版本不会补造它们。

## 启动与使用

```powershell
npm run build --prefix apps/web/client
python -X utf8 scripts/serve_probe.py --port 8766 --data-dir data/processed/shenyang-mvp-accessible-20261022
```

侧栏展开“地区与数据版本”。选择版本后点击“使用此版本”；准备期间可以取消，当前地图继续可用。
成功切换保留查询、筛选与底图偏好，清除选中并回到地区默认视图；浏览器前进/后退会恢复分享状态。
版本说明、配色、车站与线路索引先完成读取/校验，再替换铁路源与图层；不重建地图或底图控制器。
读取/校验失败不改当前地图。极少数图层安装异常也会尝试恢复原源、视图和选中记录。

## 目录与资源边界

`config/catalog.json` 显式配置区域、默认视图与候选版本，服务提供 `/catalog.json`。
启动参数指定的版本同时作为本机当前版本候选；仅保留 region 匹配、尚未过期、必要文件齐备的版本。
不会自动把 benchmark、临时构建目录或未列出的实验版本放进选择列表。
目录失败有独立重试，地图与文字列表不会因此被清空。

分享通过 `/snapshots/<snapshot_id>/...` 固定版本；服务只开放已知 JSON、详情分片和瓦片资源。
快照路径与 manifest 身份需匹配，拒绝路径穿越。原始 XML/PBF、完整中间几何与工作目录不作为此接口公开。
已有合法旧链接可以访问未在选择列表展示但仍保留的本机快照。

## 保留与回退

构建拒绝覆盖已有目录，并写入至少一年的 `retention_until`；大数据保持在 Git 忽略目录。
服务器检查到期时间：过期返回 410，文件不存在返回 404，损坏元数据返回 503。
过期/失效入口不会静默替换版本，用户可主动打开当前版本；保留视图、查询和 typed ID，
目标版本缺少该对象时明确说明，不按同名匹配其他记录。WebGL 不可用时也有文字列表恢复入口。
到期文件没有被自动删除；托管者仍需提供备份、容量监控和连续保留保障。

当前测试覆盖保留截止时间边界和本机双版本来回切换，不能证明真实服务已连续保留 12 个月。
公开托管、备份恢复和长期链接监控仍需实际部署验收；东北/全国目录需要真实数据及相应阶段验收。

## 验证

```powershell
python -X utf8 -m unittest discover -s scripts -p test_catalog.py
npm test --prefix apps/web/client
```

浏览器入口 `scripts/verify_catalog.cjs`：需设置已安装的 `PLAYWRIGHT_MODULE`，
以及指向上述服务的 `PREVIEW_URL`。它使用真实本机快照，503、损坏响应、延迟与 410 使用测试响应。
结果见 [本机浏览器证据](evidence/mvp-catalog-browser.json)。
