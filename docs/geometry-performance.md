## 改动与语义证明

`trackFilter` 对当前关闭的历史状态、以及预设下不可能出现的侧线使用固定 false 表达式。
相邻预设切换时，无效轨道层的表达式保持不变，减少地图引擎重复处理；概览/高速切换改变的轨道表达式规格从 16 降到 2，描边复用相同规格。
没有修改源详情、瓦片几何、颜色、名称布局、字体或地图引擎版本。

`verify_filter_constants.mjs` 使用已安装官方 SDK 的 featureFilter 对比归档旧表达式与当前表达式：
46 种状态、10,216 条真实记录及 2,376 个合成属性，共 11,584,640 组求值结果一致。
这证明本次表达式简化与旧渲染筛选一致，不证明旧渲染规则与全部列表规则已经一致。
合成测试发现既有边界：城市预设、关闭侧线、城市交通类型但等级为 branch/industrial 时，trackVisible 与原有侧线图层门禁存在差异。
当前源数据命中数为零，问题保留待统一，未在此次性能改动中改写规则。
新增 3 项测试后前端共 116 项通过；前两次测试失败的日志保留，分别修正 SDK 调用根键和测试对旧侧线门禁的预期。
严格 TypeScript 与生产构建通过。Chrome/Edge 搜索、筛选、列表、分享、资源恢复和字体共 12 组、86 项通过。

| render 间隔 p95 | 10.5 ms | 27.1 ms |

当前两次轨迹协议有效，终点误差小于 2 CSS px。属于合成拖动、事件提交和 RAF 代理指标，不是 GPU 完成或屏幕呈现测量，也不代表所有设备的 N03 验收。
改动前默认路径有效，render p95 18.2 ms；改动前软件路径持续 1,817,286.6 ms，最大 RAF 间隔 1,799,769.7 ms，协议无效。
该中断原件完整保留，不裁剪、不把它的 p95 当作常规软件成绩，也不能仅据此断言原因是系统休眠或应用故障。
新增 pan_protocol_guard 要求 30 秒协议实际持续 29–35 秒；无效时保存报告后失败退出。独立检查接受原有效记录并拒绝中断记录。
历史其他软件路径超标仍保留，当前一次通过不能抹去它们。

## 复现与边界

使用 `scripts/benchmark_client.cjs`、`benchmark_filters.cjs`、`benchmark_pan.cjs`；指定 `MVP_DATA_DIR` 和匹配目录名的 `BENCH_SNAPSHOT`，按各脚本入口支持的参数运行。
采样期间保持生产构建和预览不变，测量串行运行。冷启动为同一浏览器进程中的隔离上下文与禁用 HTTP 缓存，不是每次重启 GPU、服务器或浏览器。
报告含源文件、构建入口与快照指纹；归档校验了当前指纹、语义重放旧/新模型、旧平移脚本及各浏览器报告字节哈希。

真实手机/平板、Safari、读屏、完整浏览器版本矩阵、独立人工审核、公开托管及其余既有 MVP 门槛保持开放；本机结果不能替代这些证据。
