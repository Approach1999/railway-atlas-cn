# 名称缓冲成本隔离实验

2026-10-28，正式构建仍为index-DQDm9VWe.js，生产源码和数据没有修改。
脚本只拦截测试浏览器的应用响应，将名称GeoJSON源buffer从512改为128，同时捕获公开Map引用用于查询可见label_id；轨道、字体、名称候选算法、颜色和图层保持原样。

同机串行512前置对照→128候选→512后置对照，各场景30次交替筛选、10Mbps/100ms、默认Intel Arc、底图关闭。

| source-ready render p95 | 512前置 | 128候选 | 512后置 |
| --- | ---: | ---: | ---: |
| 概览 | 120.8 ms | 90.7 ms | 103.6 ms |
| 站场 | 39.4 ms | 34.2 ms | 41.3 ms |

概览/站场各自的概览与高速预设，共四组实际可见label_id：57/20/15/9条，候选未增减身份；前后对照也逐组核验，完整集合保留在原报告。
候选有继续验证的价值，但前后对照也存在明显波动，不能把全部差异归因于缓冲，更不能把30次隔离实验算作N02验收。
相同label_id不证明位置与避让优先级不变。缓冲会影响跨瓦片几何，必须继续检查标注位置、瓦片边界、不同缩放/平移和点击身份，之后才考虑正式修改及完整性能复测。
因此本轮没有把128写入产品，没有关闭正式图层或减少显示内容来宣布达标。
