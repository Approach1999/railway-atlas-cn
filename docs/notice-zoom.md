## 发现与修复

此前恢复按钮的三种CSS视口检查通过，但实际浏览器200%时，1280×800窗口得到约627×350 CSS视口。
修复前长提示框压住顶部分享/复位/面板按钮下缘，缩放控件压住提示文字。仅检查控件中心点的旧检查仍通过，截图揭示其证据不足。
加强为每个受测控件与提示框九个内缩点的命中检查后，同一原构建明确失败：提示框左上被缩放控件遮挡，三个工具栏按钮底部被提示框遮挡。

在 CSS 宽500–700px且高不超过500px的紧凑矮窗口内，提示框为左侧缩放/比例尺保留空间，调整与抽屉的间距，并把文字与恢复按钮并排显示。
其他窗口仍沿用原布局。DOM顺序、文本、筛选、动作与数据不变；没有缩小字体来容纳内容。
第一轮位置调整仍与比例尺部分重叠，九点检查拒绝；扩大左侧保留空间并处理长文本后通过。
