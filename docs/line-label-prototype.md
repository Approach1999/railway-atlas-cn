2026-10-26。当前产品仍是 index-BPD_xofR.js。本轮新增候选算法、真实瓦片隔离绘制及重放，

## 更正上一轮的来源身份推断

MapLibre 6.15 的 SymbolBucket 在 symbol-placement=line 时，会先调用 mergeLines：
将文字相同、端点相接的片段拼为长路径。该步骤没有按源 ID 分组，之后的 promoteId 跨瓦片键不能撤销这次拼接。
直接执行已安装 SDK 的同字/异字合成夹具：way/1 与 way/2 同字相接时输出一个以 way/1 标识的三点路径；
异字时仍有两个对象。运行的是逐字节相同的 SDK 源码副本，不是对它行为的模拟。

因此，上一轮 350/600 对照中的“标签关联源 ID 数量变少”是观察事实，
但“独立源对象失去标注”尚未证实：原 ID 可能只是被合并长路径保留的第一个对象。
旧构建报告保留原记录，本说明更正其原因解释；600 候选仍未采用，但不再以该计数独立证明覆盖退化。
不能依赖这些 ID 数字宣布基于来源身份的重复控制已完成。

当前真实概览进一步发现，z10 的 17 个原标签锚点距其关联 ID 的全部已加载原片段超过 2 CSS px，
最大约 361.65 px；z10.5 有 15 个，最大约 280.65 px。
这与同字拼接的机制一致，但不证明现实线路归属错误或所有点击都错误；
说明“一个标签关联到某 ID”不能单独证明锚点位于这个源片段，也应在后续 R07/R17 中检查文字点击身份。

## 候选算法

新模块 line-label-candidates.ts 只消费当前已加载 MVT 片段，不读取全区域轨道 GeoJSON，不改源数据。
以原 typed ID 为默认显示身份；只有明确、完整且非共线的城轨 line_key 才可共享显示身份。
名称仍来自源标签或已有明确线路号规则，同名不会自动合并不同源对象。

候选来自固定世界像素网格交点及片段中点，携带原 osm_id 与独立 label_id。
按来源身份做屏幕距离网格查询，保留至少 304 CSS px，为实际渲染量化预留四像素。
候选几何只是自己源片段的等长前后窗口，交给公开的 line-center 放字；
这样绕开引擎 line 模式的同字路径拼接，不需要修改 SDK。不同身份仍参与正常文字碰撞避让。
稳定排序及已有候选优先可减少平移替换；未命名、过短、不可见、退化片段不编造文字。
没有利用不可见字符或更换 OSM 身份来影响引擎。

五项新领域检查覆盖独立同名双线、同一源的邻接/缓冲片段、城轨身份与共线回退、
候选窗口中心、平移保留、输入不可变及无名/短/不可见片段。总计 89 项测试、严格类型与构建通过。
该模块尚未被产品导入；重建后的产品 JS 与上一轮哈希完全相同。

## 真实已加载片段原型

只在测试页面加入临时 GeoJSON 名称源，隐藏该页原名称层；普通产品页面没有改变。
底图关闭，轨道/车站/原始快照均保持原样。四个画面：

| 画面 | 输入轨道片段 | 接受候选 | 实际名称锚点 | 同身份最短实际间距 |
| --- | ---: | ---: | ---: | ---: |
| 概览 z10 | 4,845 | 75 | 28 | 每个已绘身份仅一份，不能据此验证重复距离 |
| 概览 z10.5 | 4,607 | 89 | 29 | 每个已绘身份仅一份，不能据此验证重复距离 |
| 西部站场 z15.5 | 86 | 23 | 14 | 305.42 CSS px |
| 电车交汇 z17 | 9 | 12 | 6 | 323.18 CSS px |

四画面均无 <300 CSS px 同身份对；站场有 11 个同身份跨瓦片对，最短 317.46 px，
电车有 2 对，最短 323.18 px。它们是这些画面的接缝见证，不是全域接缝保证。
原生锚点与接受候选的偏差最大 0.493 CSS px；四份源捕获重放生成字节相同的候选 JSON。
原始片段与候选几何仅放在忽略目录，版本库保留摘要与指纹，没有加入大原始数据。
Node 中的候选耗时仅作探索记录，不代表浏览器 UI/worker 的 N01/N02/N03 性能验收。

## 还不能采用的原因

概览 z10 原来可见 14 种文字，原型 12 种；少了于揽三线、沈佳高速线、沈山北道线、浑揽线，另增加两种。
z10.5 文字总数仍为 13 种，但少了于揽三线、沈山北道线、浑揽线，增加了其他三种。
站场与电车的文字集合保持。部分旧标签所关联的源片段实际只有约 0.9–23 CSS px，
旧引擎通过同字片段拼接才获得长路径；原型不会无证据跨不同源 way 拼接。

需要继续改善短源片段的合法标注机会、核对已有完整来源关系与同一源的瓦片片段恢复，
同时保留“不能靠同名拼基础设施线路”的 D01/R17 边界。不能只用重复距离通过而接受名称覆盖不足。
尚未实现动态平移/缩放、筛选/孤立线路、取消/版本切换、首屏就绪及候选缓存的产品接线，
也未检验倾斜视图、所有字形边界、性能、真实设备或独立来源审核。完整目标保持进行中。

运行：`node scripts/prototype_line_labels.cjs`、`node scripts/audit_line_label_prototype.mjs`、
`node scripts/verify_sdk_label_merge.mjs`。浏览器指定 PLAYWRIGHT_MODULE、PREVIEW_URL、独立 PREVIEW_EVIDENCE；
重放脚本第一个参数可指定已保存的原型目录。原型不会发布或覆盖产品配置。
