## 已确定的方案

- 首版面向铁路爱好者和基础设施探索者，提供地理图、车站搜索、要素详情、铁路类型与状态筛选。
- TypeScript + React + Vite 管理产品界面；MapLibre GL JS 绘制地图。
- Rust CLI 处理已裁剪的 PBF；Osmium 负责区域裁剪与引用保留；Tippecanoe 生成 MVT/PMTiles。
- 第一版以版本化静态数据提供服务，使用支持 HTTP Range 的存储/CDN。当前不用常驻业务 API、数据库或 WASM。
- 首次交付沈阳；东北和全国沿相同数据契约扩展，分别经过规模验收。

## 证据与当前资产

真实样本有 32,746 个 node、4,220 个 way；Rust 输出 10,692 个要素，way 节点缺失为 0。
提取重跑 PBF 指纹一致；三次 Rust 转换 GeoJSON 指纹一致。
地理图、同名车站搜索、详情与 PMTiles 分段加载已在本机浏览器验证。
见 [机器验证记录](evidence/pilot-verification.json)、[原始处理记录](../data/manifests/shenyang.json)
及 [实测截图](evidence/pilot-browser.png)。

Rust crate 与 `apps/web/probe` 是探索工具；最终 React 产品、规范化数据模型、
全国索引、生产底图、移动端验收与发布流水线尚待按实施计划建设。
