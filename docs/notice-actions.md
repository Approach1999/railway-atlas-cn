# 提示旁的直接恢复入口

2026-10-28，当前构建 `index-AnsEeJYS.js` / `index-DKP23jWq.css`。

空白提示此前只有说明，恢复按钮位于详细面板；尤其收起手机面板时，需要先找回面板再寻找开关。
现在提示旁按实际原因提供一个恢复操作：

| 提示原因 | 按钮 | 行为 |
| --- | --- | --- |
| 类型/状态全部关闭、当前视野无匹配对象、快照没有显式高速记录 | 恢复默认图层 | 使用已有概览预设，保留相机、查询、版本与底图偏好，支持已有撤销 |
| 城市线路全部关闭，或所选线路不在快照 | 恢复全部线路 | 解除线路限制，保留制式、等级、状态和其他开关 |
| 视野超出覆盖 | 回到试验区 | 使用已有复位操作，保留筛选与查询 |

MapFeedback 发布提示文本和动作类型的同一份快照，控件由 React 渲染，不按中文文本猜测操作。
普通提示、选中对象说明、加载/资源失败不提供错误的默认图层恢复；资源失败继续使用分项重试。
操作后焦点交回地图画布，避免按钮消失后键盘位置丢失。动作按钮最小高度和宽度44px，位于提示文本下方，手机面板收起时仍可用。
