# 线路等级与配色

状态：v1.2 设计基线。配色配置源为 [`config/line-colors.json`](../config/line-colors.json)，
校验脚本为 [`scripts/validate_line_colors.py`](../scripts/validate_line_colors.py)。

## 1. 目标与边界

配色要同时回答两个问题：

1. 这是哪一类铁路？高速、普速、支线、专用线、地铁、轻轨或有轨电车。
2. 如果是地铁，这是哪一条线路？优先使用运营方线路图的线路色。

v1 的颜色是**显示配置**，不是运营事实，也不改变对象身份：

- 重载铁路按**等级**配色；v1 不承诺按命名干线逐条配色。
- 城市轨道按**线路身份**配色；线路身份来自 OSM route relation 或人工配置。
- 线路色不写入 PMTiles；前端用版本化配置匹配 `line_key`，改色不需要重建瓦片。
- 颜色不是唯一区分手段：图例、线路号标签、详情和纹理必须同时可读。

## 2. 重载铁路等级

| 显示等级 | 判定 | 颜色 | 说明 |
| --- | --- | --- | --- |
| 高速铁路 | 显式 `highspeed=yes` 或审核规则命中 | `#C8102E` | 不按名称、限速或“看起来像高铁”推断 |
| 普速干线 | 显式 `usage=main` 且未标注高速 | `#1F5A8A` | 不把缺失标签推断为干线 |
| 普速/未标注 | `railway=rail`，无 `usage=main`、无高速标注 | `#4F7FA6` | 图例明确写“未标注”，不宣称具体等级 |
| 支线/站场线 | `usage=branch` 或 `service=spur/siding/crossover/yard` | `#A17A3F` | 站场侧线在高缩放才显示 |
| 专用线 | `usage=industrial` 或 `service=industrial` | `#6B4F3A` | 不推断产权或运营方 |
| 其他/未知 | 无法可靠分类 | `#8A8F98` | 不强行归入高速或普速 |

`railway=rail` 不自动等于国铁、客运、主线或高铁。高速判定规则必须版本化；
规则表与人工复核记录随 manifest 发布。

## 3. 城市轨道线路色

### 3.1 沈阳地铁

沈阳地铁未公布统一的标准色值；以下取自运营方线路图，经人工核对，
`confidence` 标记为 `operator-map`，不是“官方色值标准”。

| 线路 | 色值 | 状态 | 来源 |
| --- | --- | --- | --- |
| 1号线 | `#E5001C` | 运营中 | 运营方线路图 |
| 2号线 | `#F08439` | 运营中 | 运营方线路图 |
| 3号线 | `#E6669F` | 运营中 | 运营方线路图 |
| 4号线 | `#6E3E94` | 运营中 | 运营方线路图 |
| 9号线 | `#0095D2` | 运营中 | 运营方线路图 |
| 10号线 | `#8CBB48` | 运营中 | 运营方线路图 |

来源记录：`config/line-colors.json` 的 `operators.shenyang-metro`。
运营方线路图链接与转引页面同时保留；更新色值必须更新 `verified_at` 与 `palette_version`。

### 3.2 颜色优先级

从高到低：

1. **人工覆盖**：按 `relation_id`、`feature_key` 或 `line_key` 指定，用于官方特殊色或纠错。
2. **运营方/线路配置**：`operators[operator].lines[ref]`，支持 `ref_aliases`。
3. **OSM `colour` 标签**：仅在没有配置且值合法时使用，详情标注“OSM 标注”。
4. **制式/等级回退**：地铁回退紫、轻轨回退紫、有轨电车回退绿，其余按等级色。

未识别线路、缺失关系、共享走廊都使用回退色，不能随机挑一条线路色冒充唯一线路。

### 3.3 共线段

一条轨道可能属于多条地铁线路。v1 的处理：

- 仅当 segment 只属于一条已识别线路时，使用该线路色；
- 多条线路共享同一 segment 时，使用制式回退色并显示“共线”标记；
- 详情列出全部 `line_key`、线路名与关系完整性；
- 不通过“取第一条 relation”制造错误归属。

## 4. 生命周期与颜色组合

颜色表示等级/线路，生命周期用线型和透明度表示；停用/废弃/拆除改为中性色，
避免把历史线路画得和当前线路一样醒目。

| 生命周期 | 线型 | 颜色 |
| --- | --- | --- |
| OSM 当前标注 | 实线 | 等级/线路色 |
| 建设 | 短虚线 | 等级/线路色 |
| 规划 | 点线 | 等级/线路色 |
| 停用 | 长虚线 | 中性灰 |
| 废弃 | 点划线 | 棕灰 |
| 拆除 | 双点划线 | 棕灰，低透明度 |
| 未知 | 短虚线 | 中性灰 |
| 冲突 | 交替警示线 | 中性灰 |

选中态使用深蓝 `#154E9D` 外描边 + 白色 halo，不改变要素原本颜色。
悬停只提高亮度/宽度，不替换线路色。

## 5. 渲染与可读性

- 重载铁路线宽：高速 > 普速干线 > 普速/未标注 > 支线 > 专用线；低缩放至少保留高速与主要车站。
- 地铁线路使用比普速更粗的线宽；高缩放显示线路号标签，低缩放只显示主要换乘站。
- 浅色线路（如 2 号线橙、3 号线粉、10 号线浅绿）必须加 `#1B2A32` 深色 casing，
  不能只靠浅色线条与暖白背景区分。
- 线路色与背景的非文本对比目标 ≥3:1；达不到时使用深色 casing 或加深描边。
- 线路号徽标文字颜色由对比度自动选择黑/白，目标 ≥4.5:1。
- 颜色不是唯一编码：图例文字、线路号、线型、悬停提示和详情必须同时存在。
- 高速铁路与地铁 1 号线同为红色系，但高速用白色 casing/较粗线宽，地铁用深色 casing + 线路号；
  不能只靠色相区分。
- 图例可点击开关；线路列表提供“仅看此线”和“恢复全部”。
- 屏幕阅读器通过可访问线路列表获得线路名、等级、状态与颜色来源，不依赖 canvas。

## 6. 手工配置与覆盖

常规线路色写在 `operators.<operator>.lines.<ref>`。特殊情况写入 `overrides`：

```json
{
  "overrides": [
    {
      "line_key": "shenyang-metro/1",
      "color": "#E5001C",
      "source": "运营方线路图",
      "verified_at": "2026-10-22",
      "note": "示例：按线路键覆盖"
    }
  ]
}
```

`overrides` 可使用 `line_key`、`relation_id` 或 `feature_key` 匹配；优先级最高。
每次手工修改必须同时更新：

- `palette_version`（例如 `2026-10-22.2`）；
- `verified_at`；
- `source` 与来源链接；
- 变更说明与审核记录。

### 新增城市/线路

1. 在 `operators` 增加稳定 operator key、名称、别名、region、来源与置信度。
2. 按线路 `ref` 填 `name`、`color`、`status`；补充 `ref_aliases`。
3. 运行 `python3 scripts/validate_line_colors.py --strict`；对比度不足时确认 casing。
4. 用真实 route relation 抽样验证 `operator`/`ref` 匹配；记录未匹配原因。
5. 更新 `palette_version`，在前端构建与发布记录中引用。

## 7. 验证与限制

```sh
python3 scripts/validate_line_colors.py
python3 scripts/validate_line_colors.py --strict
```

校验内容：JSON schema、颜色格式、等级/生命周期枚举、来源与日期、重复色警告、
背景对比度、徽标文字建议、回退色完整性。
浅色官方线路会输出 `NOTICE`（要求深色 casing），不是配置错误；`--strict` 不会因
`NOTICE` 失败，但重复色等 `WARN` 会失败。

已知限制：

- 线路身份依赖 OSM route relation；关系不完整时只能覆盖已知成员，不能宣称整条线路完整。
- 共线段不强行选择单一线路色。
- v1 不提供按线路名搜索或线路详情页；线路色和线路名只用于地图识别与详情说明。
- 官方色值可能未公开；`confidence` 必须如实标记，不能把运营方图取色写成“官方标准”。
- 色值本身是事实信息；线路名称、标志和官方 logo 可能受商标保护，不随地图复制 logo。

## 8. 许可与来源记录

- 每个 operator 记录 `source`、`source_url`、`operator_url`、`verified_at`、`confidence`。
- 运营方线路图只用于取色和核对，不复制整张图或 logo。
- 详情/图例显示“配色来源：运营方线路图 / 手工配置 / OSM 标注 / 回退色”。
- 配色版本与前端构建绑定；数据快照仍由 `snapshot_id` 标识，二者不要混淆。
