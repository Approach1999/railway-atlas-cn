# 128缓冲正式候选：不采用

2026-10-28。同步修复后的512/128严格18组身份/文本/命中范围比较一致；120项测试及构建通过。构建字节验证确认候选仅把名称源buffer512替换128，没有改其他代码。128为已安装MapLibre6.15.0的默认值，但默认值不代表此项目一定更快。

同机串行、10Mbps/100ms、底图关闭、相同几何数据，各场景100次真实筛选：

| p95 | 同步修复后的512 | 128正式候选 |
| --- | ---: | ---: |
| 概览 | 86.3ms | 89.3ms |
| 站场 | 39.0ms | 55.1ms |

128有效30秒默认/软件拖动的render间隔p95为35.4/38.0ms，均超过33ms。没有本轮同步修复后的512平移对照，不能把与更早构建的差异单独归因于缓冲；但候选也未达到目标。
前一轮30次隔离诊断的约90.7ms没有转化为本轮可证实的正式收益，因此不采用128。
